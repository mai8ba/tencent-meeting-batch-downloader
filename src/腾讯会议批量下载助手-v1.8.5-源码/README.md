# 腾讯会议批量下载助手 v1.8.4

适用于 Chrome / Edge 116+。支持自己的录制目录、他人分享课程，以及视频和逐字稿下载。保留原激活码格式、3天试用、限时及永久授权。

## v1.8.4 改了什么（工作台搬进录制页，不再选文件夹）

| 改动 | 说明 |
|---|---|
| **工作台变成录制页里的面板** | 点右下角悬浮球，界面**就在「我的录制」这一页里**弹出（最大 1200×920，带遮罩）。不再另开标签页 —— 导出时录制页始终是前台活动页，Chrome 不会节流定时器、也不会 Memory Saver 冻结它 |
| **不再需要选文件夹** | 去掉本地正文校验：判定只看浏览器下载记录（`complete` + 字节数对得上 + 文件还在）。同名文件由浏览器自动存成「课程名 (1).docx」，插件不覆盖、不改名 |
| **流程从五步变四步** | ① 连接录制目录 → ② 采集清单 → ③ 开始导出 → ④ 打开下载目录 |
| **「更多」菜单下线** | 「下载他人分享课程」直接放顶栏；「全量校验 / 续导」「清空本地清单」已移除。诊断信息改为**点顶部状态行**复制 |
| **页面不在前台会自动处理** | 站点「更多」菜单是 hover 才渲染的，页面在后台/窗口最小化时菜单不弹。导出开始时会自动把录制页拉到前台；导出中途被切走会**挂起等待**，切回来自动继续 |
| **自带可见性** | 标题栏常驻启动状态灯（启动中/已就绪/启动失败/待重载）+ 版本号 + 「打开下载列表」「改下载位置」直达 |

> **升级提醒**：改动脚本后必须 **扩展页点 ⟳ 重新加载** + **录制页按 F5**，
> 两步缺一不可 —— 只 F5 不重载，页面会跑着「旧 JS + 新 HTML」的混合状态。

## v1.8.3 改了什么（按钮集中到顶部，按 1-2-3-4-5 排）

上一版的操作散在三处：选文件夹在底栏、采集在第二行、导出在底栏 —— 用户得满界面找。
这一版把**所有流程按钮收进顶部一条操作带，按顺序编号**，其他地方只剩视图，不再放按钮。

| 步骤 | 状态反馈 |
|---|---|
| ① 打开录制主页 | 没打开时是**蓝色实心高亮**（一眼看出先点它）；打开后变绿勾 + 「已打开」。点下去立刻开始每秒探测，连上就变绿，不用等 |
| ② 选择文件夹 | 已授权 → 绿色对勾 + 目录名；未授权 → 淡黄提醒「点这里授权」 |
| ③ 采集清单 | 前两步没做完时禁用，副标题直接写「要把第 1 步做完」；采集完变绿勾 + `320 项已采集 · 92 已下载` |
| ④ 开始导出 | 可导出时实心主色（全界面唯一高亮）；导出中变「导出中…」保持可见，不会淡到看不清 |
| ⑤ 打开下载目录 | 常驻可用，不受前三步状态影响 |

配套调整：

- **逐字稿校验从"非空"升级为"像不像一份完整逐字稿"**（见下方「校验范围」）：
  正文少于 50 字直接判失败并提示"确认逐字稿已生成完整"，不再把"只生成了标题"当成下载成功；
  通过时报告里会写清"正文 N 字 / M 段"。
- **底栏整个删掉**，进度条单独一条、只在任务运行时出现，平时不占位置；
- 顶栏只留品牌、连接状态、激活徽章，导航类操作（他人分享 / 全量校验 / 清空清单）收进「更多」下拉；
  「打开录制目录」从菜单里删掉 —— 它现在是第 1 步，重复入口只会让人犹豫；
- 选择条只放搜索、类型筛选、全选/反选/清空和计数，并统一 `white-space: nowrap` —— 之前窗口窄一点中文就被挤成竖排；
- 列表里类型徽章紧跟标题，不再被推到行尾；待核对的课淡黄底 + 「允许重试」按钮；
- 空状态文案跟着新按钮名改写（原来还写着「点上方采集全部清单」）。

### 调试期补充修复（版本号保持 1.8.3，未重新打包）

- **修"采集/导出结束后界面卡在任务运行中"**：终态消息原来先发、`busy` 标志后清，
  工作台收到"完成"会立刻拉一次快照，正好读回 `busy: true`；而 5 秒轮询又被 `!busy` 挡着，
  于是永久卡住 —— 表现为采集完按钮一直灰、点筛选只弹"任务运行中"。
  现在**先把标志落地再报终态**，工作台侧也不允许终态快照把 `busy` 翻回 true。
- **修"开着录制页却说没打开"**：用户按过扩展刷新（⟳）后，旧页面里的脚本会失联，
  而工作台只试用第一个匹配的标签页。现在改成按顺序试所有候选页，
  并在提示里区分「页面需刷新 (F5)」和「还没打开」，不再让用户对着一个死页面猜。
- **第 1 步会挑活着的页面**：点「打开录制主页」时优先聚焦能应答的标签页；
  若全都是失联的旧页面，会顺手刷新它，用户不用自己去按 F5。
- **修"点开始导出立刻失败：无法恢复采集时的每页条数"**：
  站点每页条数下拉的选项常带单位（"30 条/页"），而代码是整串精确匹配 `=== "30"`，
  一旦带单位就永远匹配不上 → 设置失败 → 导出在第一步整批中止。
  现在改成**只比数字**（"30"、"30 条/页"、"每页 30 条"都能读出），
  并且下拉已经展开时不再去点表头（那会把选项收起来）。
- **每页条数设不成功也不再整批停**：读得出当前条数时，按**绝对序号换算页码**继续导出；
  读不出才提示一句能照做的操作。这是最后一道保险，避免一个下拉框的问题让 100 多项都下不到。
- **本地文件找不到时多找一次**：Windows 重名会把文件改成"名称 (1).docx"，
  之前只按记录里的精确文件名找，找不到就报"不在所选下载目录"。
  现在按**去掉 (N) 后缀的名字**在所选目录（及一层子目录）再找一次，
  多个同名文件时仍然不乱认；确实找不到时，错误里会写清三种常见原因。

### 再补一条（同日中午）：修"点开始导出毫无反应"

- **按钮不再用 `disabled` 属性** —— disabled 的按钮收不到点击，浏览器直接吞掉，用户只看到"没反应"。
  改用 `aria-disabled` 表达状态，**点击永远会被处理**，并弹出一句能照做的原因
  （"请先点第 2 步「选择文件夹」并授权"这类）。
- 启动中间态加了 **45 秒看门狗**：消息通道断了会自动放行并提示刷新录制页，不会永远点不动。
- 更多菜单新增**「复制诊断信息」**：出问题时一键复制现场发给我，不用来回截图。

## v1.8.2 修了什么（"点了导出，一项都没下载"）

这是上一版遗留的**数据层**问题，不是按钮问题。

**现象**：列表里一批课程带着红字「上次点击后下载结果不明，已跳过」，点「开始导出」后进度条跑完，
但这些课一个都没下。

**原因**：导出前会先记录"我要点这门课了"（`pending` 标记），确认拿到下载 ID 后才清掉。
如果那一次点了但没有检测到下载（网络慢、弹窗没就绪、中途停止），标记会留下。
下次导出为了不重复下载，这类课一律跳过等待人工核对 —— 但它们既没被标成"已下载"，
也不会自动重试，就永久卡死了。红字看得到，却没人告诉你怎么解开。

**修法**：

- 新增 `export.v3.pending` 扁平索引，把这类课程单独列出来（升级时自动从旧记录补建，不会丢）；
- 工作台里直接可见：列表项标「待核对」并给一个「允许重试」按钮，选择条出现「有 N 项待核对 · 全部允许重试」；
- 点「开始导出」时若选中项里还有待核对，会直接问一句"先解除并一起导出 / 只导出其余 N 项"，不用再去别的页面；
- 顺手修掉一个会**制造**待核对的 bug：导出菜单没就绪时（根本没点下去）也记了"已点击但结果不明"，
  现在这种情况会立刻撤回记录，不再累积；
- 全被跳过时不再说"全部已通过校验，无需重复下载"，改为明确说明"N 项待核对被跳过，点「允许重试」可解除"。

## v1.8.1 修了什么

- **修"点开始导出没反应"**：工作台原来只要消息没抛错就把按钮锁成「导出中…」，
  即使引擎在第一道检查（未激活 / 没勾选 / 目录未授权）就退出了。现在前置条件在消息里同步判完，
  不通过就直接报错并把原因同时写到进度条上，不会再出现"按钮灰了、进度条停在正在校验、然后什么都不发生"。
- **导出起点立刻有反馈**：点下去马上显示「正在检查下载目录…」→「正在启动导出…」，
  之后的联网校时、建租约、恢复每页条数不再是一段无提示的黑屏。
- **失败原因常驻进度条**：toast 几秒就消失，现在错误会留在底栏红条上，直到下次操作覆盖。
- **录制页失联有中文提示**：页面刷新后 content script 短暂不可用时，不再显示
  `Could not establish connection` 这种原文，改为提示刷新「我的录制」。
- **新增「打开下载目录」按钮**（底栏，「开始导出」右边）：有本插件的下载记录时直接定位到该文件所在文件夹，
  没有则打开系统默认下载目录。

## v1.8.0 改了什么（界面搬到网页工作台）

这一版只改界面形态，**下载、校验、续导的逻辑一行没动**；激活码、设备申请码、已有清单与断点记录全部兼容。

### 录制页只留一颗悬浮球

以前整块面板挤在腾讯会议页面右下角：清单长了要在这个小框里滚，站点改样式还会跟着变形。
现在页面上只剩一颗 48px 的悬浮球：

- 平时就是一个「📥」图标，点了打开工作台；
- 采集/导出进行中，右上角显示进度（采集时是条数，导出时是百分比），外圈有呼吸光；
- 完成变绿、出错变红，鼠标悬停能看最后一条状态。

### 采集完自动打开工作台

点「采集全部清单」后，插件照旧在录制目录里自动翻页收齐所有条目；**采集一结束就把工作台推到前台**，
接下来搜索、筛选、勾选、导出都在网页里做，不用再回那个小面板。

### 工作台布局

从上到下只有四层，**所有流程按钮集中在第二层**：

| 区域 | 内容 |
|---|---|
| 顶栏 | 品牌、连接状态、激活徽章、「更多」菜单（打开录制目录 / 他人分享 / 全量校验 / 清空清单） |
| **操作带** | **① 打开录制主页　② 选择文件夹　③ 采集清单　④ 开始导出　⑤ 打开下载目录**，右侧「停止」 |
| 进度条 | 只在采集 / 校验 / 导出时出现，按文件个数推进，结束或出错变绿 / 变红并保留原因 |
| 选择条 | 搜索框、全部 / 仅视频 / 仅逐字稿、全选 / 反选 / 清空、`已选 N · 筛选 M / 共 T`、待核对胶囊 |
| 列表 | 勾选框、课程名、类型徽章、时间、会议号、大小、已下载标签；待核对的课带「允许重试」 |

五个步骤块自带状态：完成的打绿色对勾，**当前该做的那一步是实心主色**（全条只有一个高亮，不会到处喊你），
缺授权的第 2 步显示淡黄提醒。底栏已经删掉，进度条独立一条、平时不占位置。

### 目录授权不再跳页

工作台自己就是扩展页面，**点「选择文件夹」直接弹系统目录选择器**，选完当场确认：

1. 先用刚拿到的句柄真读一次（`queryPermission` + `entries`），读不到就报错，不写成功标记；
2. 再让校验组件（离屏文档）确认它能读到，读不到同样报错；
3. 两边都通过才落盘并显示「✅ 已授权：Downloads」。

所以不会再有"选完显示成功、到导出又要重选"的情况。浏览器把持久权限降级时会多出「恢复上次授权」，点一下就行，不用重新挑目录。

### 其他变化

- **采集不再要求先授权目录**：采集只是读页面列表，把授权卡在采集前面没有意义。授权工作台在导出前把关（未授权时导出按钮直接禁用）。
- **没打开录制页也能看清单**：工作台会读上次采集的草稿并标出"已下载"，只是导出按钮保持禁用，提示你先把「我的录制」打开。
- **弹窗变成入口**：从浏览器工具栏点开只有四个按钮（打开工作台 / 打开我的录制 / 他人分享 / 全量校验）和下载设置，不再做第二套流程。
- **页面内的 `content.css` 与授权面板一并移除**，扩展少注入一个样式表和一块 DOM，和站点样式彻底不打架。
- 分享课程控制页（`shared.html`）保持原样，仍是独立页面。

### 从 v1.7.0 延续下来的关键行为（仍然有效）

- **导出前先校验**：开始导出后先按清单做一遍本地校验，已存在的跳过、能续传的接上，只有确实没有的才点导出。视频尤其受益。
- **导出弹窗被页面重建后不空点**：每轮检查 `isConnected` 并重新定位。
- **本地校验的来源判定用 `sender.tab`**，不依赖浏览器给 Service Worker 的具体 URL。
- **逐字稿正文按需读写**：状态轮询只读元数据，不再每秒搬运 IndexedDB 全文。
- **下载 ID / 已校验记录用扁平索引**，开始任务不再读整库；升级自动补建，旧断点照常续导。
- **授权校时 30 秒缓存**，批量导出不再每项发 3 次跨域 HEAD。
- **站点选择器全部收敛在 `site-adapter.js`**，腾讯会议改版只需改这一个文件。
- **进度条按文件个数推进**（不按字节：视频大小差几十倍，按字节会长时间停在 1%）。

## 使用流程

1. 在浏览器里打开腾讯会议的「我的录制」并登录。
2. 点页面右下角的**悬浮球**（或工具栏图标 → 「打开批量下载工作台」），**面板会在当前页面弹出**。
3. 点第 ① 步「连接录制目录」—— 面板就在本页，不需要再开标签页。
4. 点第 ② 步「采集清单」，等它自动翻完所有页（结束会自动停在第 1 页）。
5. 选择条切「仅视频 / 仅逐字稿」，或直接在列表里勾；改了会自动保存。
6. 点第 ③ 步「开始导出」。进度条显示"成功 / 失败 / 共 N 项"。

> **导出期间请保持录制页在前台**（窗口最小化也算"不在前台"）。
> 站点的「更多 → 导出」菜单需要页面可见才会弹出。
> 万一你切走了，插件会**自动挂起等待**，切回「我的录制」就自动接着跑，不会丢进度。

## 文件保存与隐私

**v1.8.4 起不再需要授权任何文件夹，也不读你磁盘上的文件。**

- 判定「是否已下载」只看浏览器自己的下载记录（`chrome.downloads`）：状态 `complete`、字节数对得上、文件还在。
- 重复导出会被浏览器自动改名（`课程名 (1).docx`）保存，插件**不覆盖、不改名、不删除**你的文件。
- 文件保存位置由浏览器的下载设置决定，插件不改。想确认位置：点面板里的「打开下载列表」，或「改下载位置」。
- 插件不读 Cookie、不碰账号凭据、不上传任何课程内容；清单与下载凭据只存在本机扩展存储里。

## 勾选与筛选

- 点「仅视频」只勾视频，点「仅逐字稿」只勾逐字稿，点「全部」恢复全选 —— 筛选即勾选范围，避免"只看逐字稿，结果把视频一起导了"。
- 搜索框只影响"看哪些"，不影响"选哪些"。
- 已通过正文校验的课程标「已下载」，重新采集时**不会**被自动勾上。
- 计数按 `已选 N · 当前筛选 M / 共 T` 显示，三个数字含义不同。

## 升级和第一次使用

1. 等旧版任务停止，将新版文件覆盖到原插件加载目录，在扩展管理页面点击 **⟳ 重新加载**。沿用原目录与扩展 ID，保留设备申请码、授权和本地记录。
2. **刷新腾讯会议页面（F5）** —— 这一步不能省：面板是注入脚本，不刷新页面里跑的还是旧代码，表现为"界面正常但按钮点了没反应"。
3. 点右下角悬浮球打开面板，确认标题栏显示 **v1.8.4** 且状态灯是**已就绪**。
4. 之后全程在这个页面里操作即可，不需要再选文件夹。

## 中断与续导

- 导出运行时按钮变灰且不可重复点击。录制目录的页面点击串行进行，最少间隔2500毫秒；文件传输默认并发2，可在设置中调整。分享课程仍默认并行2门、最多6门。
- 点击"停止"会停止后续点击，并请求暂停本批已关联的下载。正在生成但尚未返回下载ID的请求无法撤回，迟到的下载在仍可关联时也会暂停。
- 再次点击开始，先核对下载记录和磁盘文件；已校验的跳过，暂停或允许恢复的下载沿用原ID继续。不能恢复的中断文件才重新导出。
- 关闭浏览器后，清单、勾选、文件ID、路径和下载凭据仍保留。重新打开录制目录或分享控制页后点击开始继续，不会仅凭旧版的"已点击/已下载"标记跳过文件。
- 已发出点击但未能确认下载的任务记为"待核对"，不会盲目重复点击。工作台列表里会标「待核对」并给一个「允许重试」按钮（选择条还有「全部允许重试」）；想先核对正本的话，去「全量校验」页看完再解除也行。
- 下载地址失效、服务端不支持断点或下载历史被清除时，不能保证接续原文件的字节位置；插件会检查文件或提示处理，保留原文件。

## 已下载标记与重复导出

- 清单里标"已下载"的课程，代表**历史记录已通过正文校验**（DOCX 解 ZIP 验 CRC 与正文；MP4 验容器、索引与媒体块），不是"点过按钮"。
- 这些课程采集后默认**不再自动勾选**，避免第二天打开时被全选、重复走一遍导出。需要重下时手工勾选即可。
- 标记按"课程 + 类型"区分：只有逐字稿校验通过时，视频仍可单独勾选，不会互相顶替。

## 空Word与重复文件处理

- 不以40785字节或文件后缀决定内容是否有效。DOCX会解压ZIP并检查CRC、正文XML和正文文字；页脚logo、空段落不算正文。
- 同名的(1)(2)(3)副本逐个验证，只在内容通过校验、与课程匹配且标题没有歧义时认领已有文件。不同文件ID的新任务分别记录，不共享"成功"标记。
- 下载显示complete但内容校验失败，会停止后续批量导出并保留待处理课程，防止继续生成大量空模板。请先在原课程页确认逐字稿是否已经生成完整，再继续。
- 所有文件均保留，包括"Tongs 的云咖啡"和"麦爸的海报制作分享课"这类没有有效同族副本的空文件。工具会标记需要补救，不自动删除或假装已恢复内容。
- 无正文、已损坏或在腾讯服务端已丢失的内容，不能从空模板里恢复。必须从课程来源重新取得。

## 校验范围与数据保存

**逐字稿（DOCX）分三层判定**：

1. **结构**：ZIP 中央目录、每个条目的 CRC、`word/document.xml` 能否解析 —— 保证文件本身没坏、没被截断；
2. **内容**：正文字数与段落数，连"是否带 `[00:12]` 时间戳"一起写进报告，方便人工对照；
3. **底限**：正文少于 **50 字**判为「只生成了标题」，**不算成功**，并提示到课程页确认逐字稿已生成完整。

第 3 条是这一版新加的。以前只判"正文非空"，于是腾讯只生成标题时，一个 28 个字的
残缺文件也会被记成"已下载"，第二天再导出时又被跳过 —— 用户以为下载完了，其实里面什么都没有。

**仍然不能证明完整**：一场 60 分钟的会如果腾讯只转了前 10 分钟，文件依旧合法、字数也可能过千，
插件识别不出来。判定的意义是把"明显残缺"从成功里摘出来，而不是假装能证明全文完整。
真正要对齐全文，只能打开课程页比对。

视频校验检查文件长度、容器、索引和媒体块，不代替逐帧播放验收。
分享逐字稿仍要求接口声明已读到末页。

课程标题、访问密码、清单和下载凭据仅保存在当前浏览器本地，供断点恢复使用；分享页"清空"会移除清单和密码。课程正文缓存按任务清理，不上传到外部服务器。

设备申请码由本地安装标识派生（不是硬件指纹）：清除扩展数据或换浏览器配置会生成新码，试用也会重新开始。这是纯本地验签的必然取舍。
