# 麦爸 · 腾讯会议插件激活与发码

## 用户使用流程

1. 加载 v1.5.5 扩展，打开扩展图标或腾讯会议“我的录制”右下角面板。
2. 激活区自动显示**设备码（设备申请码）**。点击“复制设备申请码”。
3. 按提示操作：**将设备码发给麦爸（mai8ba），找麦爸购买激活码。**
4. 收到激活码后，粘贴到输入框，点击“验证并激活 / 续费”。
5. 验证通过后会显示“已激活 · 永久有效”或“已激活 · 有效至……”，采集和导出按钮解锁。

有效期到期后，继续把原申请码交给麦爸，购买新的激活码即可续费。可以从限时授权升级为永久授权，程序会避免误用旧码缩短已有有效期。

## 麦爸发码流程

1. 在自己电脑打开原有 **兑换码生成器-私钥内嵌版-请勿分发.html**。
2. 将用户复制的申请码粘贴到生成器“设备申请码”一栏。
3. 二选一：
   - **永久有效**：没有到期日期。
   - **指定到期日**：选择日期，授权截止到管理员电脑所在时区该日 23:59:59。
4. 点击生成并复制兑换码，把结果完整发给对应用户；这个兑换码就是插件中的“激活码”。
5. 续费时使用同一个申请码，选择更晚日期，重新生成即可。

不需要改造原生成器，也不需要重新生成密钥。若在原生成器中更换私钥，当前插件公钥将无法验证新码，需要同步更新插件的验签公钥。

## 分发与升级

- 只分发 **tencent-meeting-batch-download-v1.5.5.zip**，不要混用没有激活功能的 v1.3.0。
- ZIP 内包含扩展、公钥、说明和测试，不包含私钥或私钥生成器。
- 用户升级后续版本时，覆盖原加载目录并重新加载扩展；不要先卸载，避免扩展 ID/数据改变。
- 申请码由安装标识派生，绑定当前浏览器配置中的扩展安装，不是硬盘、主板等硬件序列号。同一电脑换 Chrome/Edge 或换用户配置也会变化。

## 已实现的校验

| 情况 | 处理 |
|---|---|
| 未激活 | 禁止采集、导出和自动下载分类 |
| 有效的限时码 | 显示到期时间，允许使用 |
| 有效的永久码 | 显示永久有效，允许使用 |
| 激活码属于另一申请码 | 拒绝激活 |
| 手改日期、设备字段或签名 | 拒绝激活 |
| 已到期 | 禁止启动新操作，可以购买续费码 |
| 下载进行中到期 | 不强制取消已启动的浏览器下载，后续导出停止 |
| 电脑时间被前调或回拨 | 仍以联网获得的时间判定，不延长有效期 |
| 断网或无法取得一致的服务器时间 | 暂停限时授权，恢复联网后重试 |
| 重启浏览器或扩展 worker | 从本地授权重新验签恢复，无需再次输入 |

授权在后台校验，采集每页、下载排队和最终点击前均检查；不仅是隐藏按钮。激活信息改变后会同步到已打开的面板，状态展示每 30 秒刷新一次，实际操作时会重新检查。

## 联网校时与防护边界

签名仍在本地验证，但限时有效期改用实时 HTTPS 服务器时间。每次校验请求三个来源，至少两个时间一致才使用；断网或来源异常时不使用本地时间或历史成功时间兜底。仅调整电脑日期不能延长授权。

普通浏览器扩展本身仍可被修改源码；控制系统信任证书、复制浏览器配置等需要更完整的授权服务防护，不能把联网校时视为不可破解。

本版联网只用于获取公开站点时间，没有远程授权账户、吊销、按硬件序列号绑定或支付接口。取时请求不包含申请码、激活码和会议信息。后续要控制设备迁移和远程停用，应增加服务器验权。

## 本次验证

- 80 项自动化测试全部通过（含原私钥 HTML 的实际签发兼容性测试）。
- 独立 Edge 浏览器配置中加载真实扩展，实际联网取时后，将 worker 的 Date.now 分别模拟为 1970 年和 2200 年，限时授权结果不受影响；模拟断网后立即拒绝新操作，恢复真实网络后恢复。
- 模拟服务器时间越过截止日期，同时把电脑时间接口设为 1970 年，仍拒绝到期授权。未修改操作系统时钟。
- 保留原生成器兼容性、永久升级、设备错配、刷新保留和网页面板同步验证。
- 腾讯会议内容脚本测试使用受控列表页面，未登录真实账号执行下载；原有网页适配仍需实机验收。

技术依据：[Web Crypto 验签](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/verify)、[Chrome 扩展本地存储](https://developer.chrome.com/docs/extensions/reference/api/storage)。


## 升级要点

用 v1.5.5 文件覆盖原加载目录，保留原扩展 ID 与数据，再到扩展管理页点击重新加载。原设备码和激活码可继续使用，不要卸载后新建安装。新增加的 qq.com、baidu.com 访问权限用于 HTTPS 取时。首次升级请确认这些权限已获准，再刷新腾讯会议页面。

永久授权不要求联网校时；限时授权取时失败会提示网络异常。管理员生成指定日期的步骤不变。


## v1.5.5 界面

激活成功后，设备码和续费表单自动折叠，保留授权状态和展开入口；到期后自动展开。原发码格式、设备申请码和联网到期判断继续兼容。自己的录制采用“进入录制目录 → 采集全部清单 → 开始导出”，每页固定 30 条。新增“下载他人分享录制课程”可解析整段文本并批量处理，下载操作同样必须通过授权校验。
