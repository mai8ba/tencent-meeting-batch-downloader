# v1.8.24（2026-11-24）：修「150 项只报成功 32」——数字被吞 + 整批中止 + 自动降级

麦爸导出 150 项逐字稿，结果只显示「成功 32，失败 5」，还挂着一条
"更多菜单未找到可点击的『导出』"。查下来是三个真 bug 叠在一起。

**1. 数字被吞了（最严重）**
`exportSelected()` 只返回 `{started, total}`，没带 `done / failed`。
按标签导出时调用方写的是 `done += r.done || 0` —— 永远加的是 0。
于是"清单页快路"那一整组的战果全部消失，屏幕上只剩详情页那组的 32 / 5。
用户会以为只下成功了 32 个，其实硬盘上早就有更多文件。

**2. 一项点不开，整批收工**
站点菜单靠 hover 渲染，录制页一被切到后台就弹不出来（现场诊断 `pageHidden: true`、
`matched: 0`、`visibleMenu` 里全是语言/每页条数这类无关下拉）。
老代码遇到这种情况直接 `throw`，150 项里卡在第 38 项，后面 112 项一项没跑，
前面跑完的也因为第 1 条而没报数。

**3. 没有兜底**
菜单点不开就是死路。但其实同一份逐字稿在详情页接口里也有一份，不必非走"更多 → 导出"。

**这次改动**
- `exportSelected()` 返回 `done / failed / failedItems`，每项失败都带原因码
  （`menu-miss` / `uncertain` / `verify-failed` / `row-missing`）。
- 单项菜单点不开 → 记这一项失败、继续下一项，不再中止整批。
- 连续 5 项都点不开 → 熔断停批并说清原因（否则每项白等 5 秒，上百项就是十几分钟）。
- 进 hover 循环前再确认一次前台状态；页面切回来会重新给一轮 5 秒预算。
- **自动降级**：清单页快路点不开菜单的项，自动改走详情页抓取，成功的算成功。
- 终态消息带上"首个失败原因"，并保证 `成功 + 失败 + 未处理 = 总数`，不再有黑洞。

**测试**：228 项，227 通过 1 跳过（新增 4 项：不整批中止、连续熔断、返回值带统计、降级）。

# v1.8.23（2026-11-24）：逐字稿排版对齐腾讯官网 Markdown，存成 .md

麦爸平时下载逐字稿的习惯是：进详情页 → 选 Markdown → 点官网「下载」。
对比发现官网 md 和插件抓到的内容其实是**同一份数据**（时间戳、发言人、正文都对得上），
只是排版不同。于是把插件的输出改成和官网一模一样的 Markdown 排版。

**官网排版长这样**：
```
张菲菲(00:00:55):
来了。

5 麦爸(00:00:58):
要没那么早，还得干活。
```
- 发言人行：`发言人(时:分:秒):`，时间是六位含小时（00:00:55）
- 下一行正文，段与段之间空一行

**这次改动**：
1. 逐字稿正文按官网排版输出（原来是 `[00:55] 发言人：正文` 一行式）。
2. 文件后缀从 `.txt` 改成 `.md`（文件名仍是「日期_课程名_会议号_逐字稿.md」）。
3. 时间从 `mm:ss` 补齐成官网的 `hh:mm:ss`。
4. 文件仍带 UTF-8 BOM，Windows 记事本打开不乱码。
5. `site-adapter` 认得 `.md` 是逐字稿（下载归类/校验不出错）。

**验证**：用真实接口数据生成的内容，与麦爸下载目录里官网下载的 md 文件逐字节一致。
v1.8.22 的"没字幕就跳过、不存垃圾"保护仍然生效。

以下是上一版 v1.8.22 的改动：

## v1.8.22：修复"逐字稿导出成一堆播放器界面文字"

有用户反馈：同样是导逐字稿，一份正常（带时间戳的对话），另一份却是一堆乱七八糟的文字
（"放大字体""Transparency/不透明半透明背景""Esc 键退出全屏""暂时无生成字幕内容"）。

**根因**：那份会议本身没有生成字幕。接口快路没数据时，程序退回读网页文字；
找不到逐字稿容器就退化成读整个页面，把播放器的设置说明、空态提示全当正文抄了下来，
还把 `12:40` 这种界面数字误当成了时间戳。

**修复**：
1. 只有找到真正的逐字稿容器才允许"读网页文字"兜底；退化到整页时只认标准段落节点，不再全页乱抄。
2. 加"验货"关卡：抓到的内容若含播放器设置文案、或一条合法时间戳都没有，一律判为失败，不保存。
3. 失败时给出明确提示——"这场会议没有生成逐字稿/内容不像逐字稿，已跳过"，不再悄悄存一份垃圾文件。

正常逐字稿（接口快路、或真容器里带时间戳的对话）不受影响。

# 腾讯会议批量下载助手 v1.8.5

发布日期：2026-11-02。适用于 Chrome / Edge 116 及以上版本。

## 安装与升级

首次安装：解压成品包，在浏览器扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。

已有用户升级：先停止导出并等待传输结束，备份当前插件文件夹，再将成品包内文件复制到原来已加载的插件文件夹。保持原路径，在扩展管理页点“重新加载”，再回录制页按 F5。不要移除扩展重装，以免丢失设备授权、清单与下载记录。

## 使用

打开 https://meeting.tencent.com/user-center/meeting-record 并登录。点击录制页右下角悬浮按钮，工作台会在同一页面展开。依次连接录制目录、采集清单、勾选课程、开始导出。页面每页固定 30 条；导出时保持录制页前台。

可随时停止，之后继续导出。判断完成依据为浏览器下载记录的完成状态、字节数和文件存在状态；不再要求选择文件夹，也不读取 Word 正文。因此不能保证腾讯服务器生成的逐字稿非空或完整。

文件保存到浏览器设置的下载位置；可从工作台“改下载位置”打开设置。连续下载请关闭浏览器的“下载前询问每个文件的保存位置”。同名文件由浏览器自动添加后缀，不覆盖已有文件。

分享课程入口支持粘贴整段分享文本、识别课程及密码，选择视频或逐字稿下载。只下载您有权访问和保存的录制。

保留 3 天试用、设备申请码、限时及永久激活。需要激活时，将申请码发给麦爸（mai8ba）。有效期按联网校时判断。私钥生成器不随成品或源码包分发。
