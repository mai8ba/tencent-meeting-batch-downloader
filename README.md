# 腾讯会议录制批量下载助手

在腾讯会议「我的录制」页里，**贴边一个抽屉**，批量把录制视频和逐字稿下载到本地。

- 版本：v1.8.22
- 协议：[MIT](LICENSE) —— **完全免费，没有任何使用限制**（无试用期、无激活码、不联网校时）
- 平台：Chrome / Edge（Manifest V3 扩展）

---

## 它能干什么

| 能力 | 说明 |
|---|---|
| 一键采集清单 | 自动翻页读完整个「我的录制」，上百条课程一次收齐 |
| 智能区分类型 | 按**文件大小**判断：没标大小的 = 只有逐字稿；标了 MB/GB 的 = 视频 + 逐字稿 |
| 批量导出 | 勾选后批量下载；视频走页面原生导出，逐字稿自动进详情页抓取 |
| 并行提速 | 逐字稿同时开 3 个详情页抓取，比一个个来快 2~3 倍 |
| 分类归档 | 自动存到 `腾讯会议录制下载/日期_类型/` 目录，视频与逐字稿分开放 |
| 命名清晰 | 逐字稿文件名为 `日期_课程名_会议号_逐字稿.txt`，不会变成"下载一""下载二" |
| 断点续导 | 按浏览器下载记录判断哪些已经下过，只导缺的 |

## 安装

### 方式一：拖 zip（最快）

1. 到 [Releases](https://github.com/mai8ba/tencent-meeting-batch-downloader/releases) 下载 `tencent-meeting-batch-downloader-v1.8.22.zip`
2. 打开 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 把 zip **直接拖进页面**
5. 打开腾讯会议「我的录制」页，按一次 **F5**

### 方式二：加载已解压的扩展程序

1. 克隆本仓库，`extension/` 目录就是完整的扩展
2. `chrome://extensions` → 开发者模式 → 「加载已解压的扩展程序」→ 选 `extension/` 目录
3. 打开腾讯会议「我的录制」页，按一次 **F5**

> 装完必须刷新录制页，否则页面里跑的还是旧脚本。

## 使用

1. 打开腾讯会议 → 用户中心 → **我的录制**
2. 页面**右边缘**会出现一个竖排把手，点它，右侧滑出工作台
3. 按第 1 步连上录制目录 → 第 2 步采集清单
4. 在列表里搜索 / 筛选（全部 / 仅视频 / 仅逐字稿）、勾选要导出的课程
5. 点「开始导出」

- 类型按钮只做筛选，**不会替你勾选**，勾不勾由你决定
- 点复选框、点课程名都能切换勾选
- 按 `Esc` 或点遮罩收起抽屉

## 文件放哪

```
腾讯会议录制下载/
├── 2026-11-24_视频/
│   └── 课程名.mp4
└── 2026-11-24_逐字稿/
    └── 20261124_菲菲辅导麦爸_235263476_逐字稿.txt
```

同名文件不会被覆盖，浏览器会自动在文件名后加序号（如 `(1)`）。保存位置由浏览器的下载设置决定。

## 隐私

- 全部逻辑在你自己的浏览器里跑，**不收集任何数据**、不上传任何东西
- 只访问 `meeting.tencent.com`（腾讯会议）和浏览器自己的下载接口
- 源码里唯一与网络有关的代码是腾讯会议页面本身的数据请求

## 目录结构

```
extension/   扩展运行时文件（可直接「加载已解压的扩展程序」）
src/         完整源码，含 tests/（node --test tests/*.test.cjs）
release/     打包好的 zip（拖进 chrome://extensions 即可）
```

## 开发

```bash
cd src
node --test tests/*.test.cjs     # 跑全部用例
```

源码目录 `src/` 就是扩展本体，`extension/` 是它的运行时副本（不含测试）。
改动流程：在 `src/` 改 → 跑测试 → 同步到 `extension/` → 打包 zip → 发 Release。
